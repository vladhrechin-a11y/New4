# Підтримка Поруч — GitHub Pages

1. Завантажте всі файли цієї папки в корінь існуючого GitHub repository.
2. Settings → Pages → Deploy from a branch → main → / (root).
3. Відкрийте GitHub Pages за HTTPS.
4. Перший запуск зробіть з інтернетом, щоб Service Worker зберіг локальні файли.
5. Після цього перевірте режим польоту.

Дані методички знаходяться у `offline-data.js` і формуються з Excel.
Зовнішні фото з Google Drive у цій версії не використовуються.

## Фото генераторів
Фото для розділу G прив’язані за назвами `G-крок.підпункт` (наприклад, `G-3.2`). Якщо для одного підпункту два фото, використовуються `G-3.2-1` та `G-3.2`.
